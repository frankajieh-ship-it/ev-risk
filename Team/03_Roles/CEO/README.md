# CEO & Product Owner

**Mission:** make sure we build something buyers will use and pay for, not just a more complicated chatbot.

**Primary KPI:** buyers who got real value from the result and showed they'd pay for it.

**Responsibilities**
- Set the product vision and approve the first customer segment
- Decide which existing OFFO tools to keep, combine, improve or retire
- Interview potential EV buyers and review the team's feedback
- Define what a successful Buying Report must contain
- Approve the pricing experiment and launch criteria
- Review weekly progress, remove blockers, control scope

**Owns:** `00_HQ/`, `01_Comms/ANNOUNCEMENTS.md`, the Monday sync file, `06_Legal/`, `02_Projects/buying-agent/PRD.md`.

**Weekly rhythm**
- Mon: publish the weekly sync with assignments and that week's gate
- Ongoing: clear `@CEO` items on the board within 48h; log every decision in `DECISIONS.md`
- Fri: read every update, make the go/no-go call, refresh `PRIORITIES.md`
