# Research

| Folder | Contents | Naming |
|---|---|---|
| `buyer-interviews/` | One file per interview (use `_templates/interview-notes.md`) | `YYYY-MM-DD_initials.md` |
| `community/` | Reddit/forum findings, recurring questions, quotes with links | `YYYY-MM-DD_topic.md` |
| `market/` | Competitors, pricing benchmarks, data-provider evaluations | `topic.md` |

Every 5 interviews, Growth writes `buyer-interviews/SYNTHESIS.md`: patterns, surprises and what should change in the product. Never store full names, emails or phone numbers.
