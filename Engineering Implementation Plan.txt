Engineering Implementation Plan

Product: Reddit Operator Tool
Goal: Generate Reddit-ready replies that match Founder voice + decision logic, with robust link gating and operator UX, and improve over time via logging and evaluation.

North Star Outcomes

Replies are direct and specific to the post (no generic predictability talk unless it is actually the question)

Link sharing matches policy (only when appropriate, otherwise no link or no good posts)

Operators can work fast (paste URL, review extracted signals, copy reply)

System is robust over time (linting, strict schema outputs, intent routing, learning loop)

Phase 0: Baseline architecture update
Deliverables

Separate “Operator UI” from “Blueprint doc”

Add a “Decision Object” output contract across the system

Add basic logging table for every analyze event

Acceptance criteria

Every Analyze returns a structured object, not just text blocks

Operator UI loads without scrolling past large doc content

2) Add Decision Panel above replies
Change

Add a “Decision” card that always renders after Analyze:

Decision: NO_GOOD_POSTS, REPLY_NO_LINK, REPLY_WITH_LINK, REPLY_WITH_LINK_AND_INVITE

should_share_link: yes or no

scenario_slug: chosen slug or null

should_invite_evroutine: yes or no

Behavior

Hide reply boxes

Show label + rationale only

Acceptance criteria

No reply copy shown for NO_GOOD_POSTS

3) Add Rule Linter before output is copyable
Lint rules

Hard fails:

Contains quotation marks

Contains italics markers (underscore or asterisk formatting)

More than one link

Slash example pattern like x/y or word/word

Exceeds max length for selected tone

Soft fails (warning + suggested regen):

Promotional language

Too generic (no direct answer within first sentence)

UI behavior

Output text shows lint status: Pass or Needs Fix

If fail, show Fix button that triggers a “format correction regen” pass (no content drift)

Acceptance criteria

Copy button disabled if lint hard fails

Fix regenerates within the same intent and structure
